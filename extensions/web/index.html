Guardrails

Security posture of this dashboard (loopback-only):

  • Loopback only — the server refuses any non-loopback bind (127.0.0.1 / localhost / ::1).
  • Zero outbound calls — the dashboard only listens locally and streams the in-process event bus; it never opens an outbound connection.
  • Same-origin — the page talks only to the loopback origin it was loaded from, via relative /api/* paths. No wildcard CORS.
  • Session token — state-changing writes are authorized with a per-session token injected at serve time.
