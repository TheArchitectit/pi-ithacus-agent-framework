# Pi Ithacus Agent Framework

A TypeScript-based AI agent framework with guardrails, sprint task management, LSP integration, cost tracking, and collaborative agent workflows. Designed for self-hosted LLM inference with multi-provider support.

## Features

- **Guardrails** — Prevention rules, pattern matching, and safety protocols for AI agents
- **Sprint Task Framework** — Structured task tracking and sprint planning
- **LSP Integration** — Language Server Protocol support for code-aware agents
- **Cost Tracking** — Token usage and cost metrics across providers
- **Model Profiles** — Multi-provider model configuration and routing
- **Checkpoint System** — Session state persistence and recovery
- **Collaborative Agents** — Multi-agent task routing and review workflows
- **Compact Context** — Vector-backed context compression for long sessions

## Tech Stack

- TypeScript
- Node.js
- Designed for local LLM inference (llama.cpp, Ollama, OpenAI-compatible providers)
